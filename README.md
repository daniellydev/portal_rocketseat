# Portal de Notícias Tech

Projeto desenvolvido com HTML5 e CSS3, simulando a página inicial de um portal de notícias voltado para tecnologia. O objetivo foi praticar a construção de layouts modernos utilizando CSS Grid, organização visual de conteúdo e boas práticas de desenvolvimento Front-end.

## Sobre o projeto

Este projeto reproduz a interface de um portal de notícias sobre tecnologia, apresentando manchetes, destaques e conteúdos organizados em diferentes seções.

Durante o desenvolvimento foram aplicados conceitos de estruturação semântica, organização de layouts complexos e estilização utilizando recursos modernos do CSS. O projeto foi desenvolvido como prática dos conteúdos estudados na Rocketseat.

## Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/daniellydev/portal_rocketseat.git
```

2. Acesse a pasta do projeto:

```bash
cd portal_rocketseat
```

3. Abra o arquivo `index.html` em seu navegador.
